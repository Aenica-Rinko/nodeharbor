# 新用户试用记录

目标：验证陌生用户能否独立完成获取和导出，以及失败后能否恢复。此文档是待执行方案，不代表已完成真人试用。

建议邀请 3–5 位未接触过项目的用户，自愿使用各自的测试环境。主持人先观察，不提前指出按钮位置；不收集订阅正文、节点凭据、私人路径或未经同意的屏幕录像。

| 任务 | 完成标准 | 记录 |
| --- | --- | --- |
| 从解压到配置核心 | 能确认检测核心有效并保存设置 | 用时、求助次数、停顿位置 |
| 选择来源并获取 | 能解释下载成功与检测通过的区别 | 用时、是否误以为已导出 |
| 导出到已有客户端 | 能独立找到对应文件/链接并导入 | 客户端版本、是否重复导入 |
| 再次更新 | 能解释旧文件副本为何不自动同步 | 是否理解追加与替换 |
| 获取失败或取消 | 找到失败原因与下一步，已有导出保留 | 恢复操作、是否需要帮助 |
| 区分来源类型 | 理解 Cloudflare 是托管类型而非官方节点 | 用户原话的匿名摘要 |

每人记录应用版本、Windows 版本、分辨率与缩放；每项记录开始/结束时间、是否独立完成、最困惑的一句话。不要把测试者姓名或配置写进公开 issue。

优先修复导致任务无法完成、误删已有结果或误解可用性的阻碍。时间指标先收集基线，不用预设的“几分钟完成”替代实测。修复后让未参与设计的人复测同一任务。

真实协议流量、UDP/QUIC 与长期可用性应使用维护者可控服务另行验证；GUI 任务试用不能替代网络验收。
